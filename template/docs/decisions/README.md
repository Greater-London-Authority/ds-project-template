# Decisions

One short file per decision that someone later would otherwise have to work out again:
a choice of method, data source, layout or tool, and why.

Name files `NNNN-short-title.md` (`0001-use-gla-data-for-parcels.md`), with:

- **Date and status**: proposed, agreed (by whom), or replaced by `NNNN`.
- **Context**: what had to be decided, and what was known at the time.
- **Decision**: what was chosen.
- **Consequences**: what follows from it, including what it rules out.

Don't rewrite an agreed decision. When it changes, add a new file and mark the old one as
replaced.
